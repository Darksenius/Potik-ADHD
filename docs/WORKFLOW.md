# Робота над Потоком без зайвих витрат

Узгоджено з власником 10.10.2026.

- Основний агент визначає поведінку задач, межі ітерації та перевіряє результат. Не дублює повний аналіз субагента.
- За потреби GPT-6 Luna виконує окремі зміни, тести й перевірки; незалежні завдання можна виконувати паралельно. Кількість агентів і рівень міркування обирає основний агент за складністю та користю. Це запропонований спосіб економії, а не обов'язкова схема. Передавати лише потрібні файли й критерій готовності, без усієї історії чату.
- Одна ітерація — один завершений користувацький сценарій. Нові сторонні знахідки записувати у дорожню карту, не розширювати поточну роботу без потреби.
- Пріоритет релізу, уточнений власником 12.10.2026: людина завантажує останній публічний APK, встановлює й одразу користується. Обов'язковий критерій — чисте встановлення, перше збереження задачі з нотаткою та збереження після повного закриття. Несумісні старі дані автоматично потрапляють в архів, доступний у налаштуваннях, без рішення про відновлення. Зворотна сумісність не є умовою готовності.
- Під час змін запускати цільові перевірки. Повний набір — перед кандидатом або коли зачеплено спільний механізм. Після успішного результату не повторювати його без нових змін чи конкретної причини.
- На помилку автоматизації — коротка діагностика і до двох виправлених спроб; далі переглянути спосіб перевірки, не запускати нескінченно весь сценарій.
- Зберігати зміни окремими комітами. Готовність позначати точно: реалізовано / перевірено автоматично / перевірено на емуляторі / перевірено власником на телефоні.
- Звіт: що тепер працює, як перевірено, де APK, що залишилося. Не створювати повторні великі аудити й документи замість роботи.
- Умова завершення, підтверджена власником 10.10.2026: після готовності й перевірок запушити фінальні зміни та відповідний версійний тег на GitHub, опублікувати підписаний APK у GitHub Releases з описом змін і результатами перевірок. APK має бути доступний для завантаження так само, як попередні версії; одного локального файла чи тимчасового артефакту Actions недостатньо. Публікація готової версії вже дозволена власником і не потребує повторного запиту. Автозбірка спочатку створює чернетку релізу; після перевірки APK її потрібно опублікувати та звірити доступність вкладення. Чітко вказати фактичні межі перевірки, включно зі станом перевірки на фізичному телефоні.

Опубліковано r5: перевірено десять типів задач, спільні нотатки, редагування пунктів чекліста, лічильник як додаткову властивість задачі та «Воду» як просту щоденну задачу з кроком 100 мл. Досягнення цілі лічильника й виконання всіх пунктів не завершують задачу автоматично: завершення лишається окремою ручною дією. У шторці є явні «+ Задача» та «+ Нотатка»; повтори, скасування й нативні дії перевірено на повторне нарахування XP та збереження. CI 107/107, Android 9 16/16, підписаний APK і його публічне завантаження підтверджені: [звіт r5](qa/tasks-notifications-2026-10-13.md). Перевірки на фізичному телефоні ще немає. Наступна окрема ітерація — повна історія повторів як окремих входжень; зараз календар показує майбутні входження без такої історії.
