# Потік як панель квестів

14.10.2026. Контракт задуму після розмови з власником. Нові правила шторки ще не реалізовані й не випущені. Гілка `improve/quest-panel-2026-10-14`, база — `v1.7.6.r5`.

## Призначення

Потік допомагає вибрати доречну дію в поточному напрямку життя. **Часова зона і є напрямком.** Окремого нового перемикача «Дім / Робота / Навчання» не додаємо. Гіперфокус залишається записом фактичної уваги, а не другим фільтром задач.

«Підмести підлогу → Вечір» не заважає в Обід. Задача лишається незавершеною та доступною в Плані/всіх задачах. Пропущений вечір її не видаляє; при наступному Вечорі вона знову доречна.

## Основа попередніх версій

Прочитані довідки `v1.7.0`, `v1.7.4`, звичайної `v1.7.5`, а також її фактичний добір задач та Android-дії.

- Довідки послідовно описують «що краще зараз?», час як контекст і захоплення імпульсів: [1.7.5, рядки 884–886](https://github.com/Darksenius/Potik-ADHD/blob/v1.7.5/www/index.html#L884).
- Прив'язані справи й планові заміни зон дня: [рядки 912–915](https://github.com/Darksenius/Potik-ADHD/blob/v1.7.5/www/index.html#L912).
- Основний список ранжував також чужі зони замість відсіву: `renderTasks`, рядки 2175–2191. Довідка й код не в усьому збігалися.
- Шторка брала сім задач і виключала закріплені пріоритети: `fgNotifText`, рядки 3948–4080. Нове рішення власника — п'ять, із доречними пріоритетами першими.
- Android-відкладання ставило нагадування на годину, а JS лише опускав запис униз. Повернення після наступної зони та дії «Не сьогодні» там не було. Нові правила мають усунути цей розрив.

## Підтверджені правила

| Умова або дія | Результат |
|---|---|
| Поточні квести | Доречні зараз незавершені справи. Чужа зона не потрапляє сюди через високий пріоритет. |
| Закріплений пріоритет | Першим серед п'яти, якщо підходить поточній зоні й дозволений датою/часом. |
| «Розгорнути» | До п'яти окремих простих карток із поточного добору. На кожній: «Виконано», «Не зараз», «Не сьогодні». Швидкий запис задачі й нотатки зі шторки залишається. |
| «Виконано» | Завершити саме показану задачу/входження. Зміна порядку не має спрямувати команду на інший запис. |
| «Не зараз» | Тимчасово запропонувати в наступній часовій зоні сьогоднішнього фактичного плану. Не переписувати постійне призначення назавжди. |
| Наступна зона закінчилась без дії | Повернути в попередню зону й показати при наступному входженні в неї. До того запис доступний у Плані/всіх задачах. |
| «Не зараз» в останній зоні сьогодні | Одразу застосувати правило «Не сьогодні». |
| «Не сьогодні», є прив'язка | Завтра у власну зону задачі. |
| «Не сьогодні», немає прив'язки | Рівно на 23 години від натискання; пізніше відкриття застосунку не починає відлік заново. |
| Вода | Немає окремого водного шару й автоматичної задачі води. Загальний лічильник лишається властивістю користувацьких задач. |

При кількох послідовних «Не зараз» попередня зона означає ту, з якої зроблено останнє перенесення. Це робоче трактування слова «попередня»; постійна прив'язка серії не переписується.

Швидка проста задача без дати: очікується відповідь власника — доступний універсальний квест одразу чи лише Вхідні до планування. У 1.7.5 вільна задача могла бути доступна одразу; r5 вимагає планування для виходу зі Вхідних.

## Сценарії для перевірки задуму

| Сценарій | Очікування |
|---|---|
| «Підмести» у Вечорі 18–20; зараз Обід | Немає в поточних квестах/п'яти картках, знаходиться в Плані та всіх задачах. |
| О 18:10 «Підмести» → «Не зараз», наступна зона 20–22 | До 20:00 прихована; у 20–22 доступна там. Якщо нічого не зроблено, після 22:00 чекає наступного Вечора. |
| Прив'язана справа → «Не сьогодні» | Завтра у власну зону, а не довільні 15 хвилин чи першу зону завтра. |
| Вільна справа → «Не сьогодні» о 15:40 | Прихована до 14:40 наступного дня: це 23 години, а не лише нова дата. |
| Вісім доречних справ, дві закріплені | «Розгорнути» дає п'ять карток, закріплені першими. Решта не видаляються. |
| Пріоритетна вечірня справа о 12:00 | Пріоритет не обходить обмеження зони. |

## Реалізація без розходження між екранами

Зберегти поточні задачі; відділити постійне призначення, тимчасове перенесення виконання та добір поточних квестів. Перенесення не є новою копією, виконанням чи видаленням.

Панель і шторка мають однакові правила доступності та порядку. Спочатку відсів чужих зон/майбутніх дат/відкладеного, потім сортування. Android-команда зберігає ID, момент натискання й дані перенесення; відкриття застосунку пізніше не змінює строк або обрану зону.

Окремі краї перед реалізацією: видалена зона, відсутність зони в завтрашньому плані, перенесення задач на точний час. Запис має лишатися знайденим у Плані/всіх задачах із поясненням, а не зникати.

Порядок: один наскрізний сценарій «Підмести → наступна зона → повернення», обидва варіанти «Не сьогодні», п'ять карток Android без відкритого застосунку. Перевірки підтверджують ці сценарії; кількість тестів не доводить правильності задуму.

## Зроблено в коді цієї гілки

Прибрано автозаповнення води. Старий відповідний лічильник переноситься в кошик один раз зі збереженням прогресу; старий `r1` води прибирається. Позначка міграції дозволяє пізніше створювати довільні власні задачі. Цільова перевірка 1/1 та production-збірка пройшли. Публічний r5 ще містить стару стартову воду; ця зміна не випущена.
