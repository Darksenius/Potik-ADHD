  копія; зовнішні записи раз на 5 хвилин і примусово перед фоном; відновлення

  У вебfallback максимум три унікальні записи замість рекурсивного previous.
- [x] C: виміряти синтетичний рік; прибрати items лише з нових подій історії;
  старі поля читати. Retention/compaction не впроваджувати, наслідки описати окремо.
- [x] D: fullBackupContent і dataExtractionRules; виключити recovery, staging,
  точні тимчасові файли й нечинне після переносу SAF призначення. Room включений.
  Маски *.tmp Android не підтримує.
- [x] E: правило Migration + test для кожної нової версії Room; заборона
  destructive migration; правдиві коментарі, фінальні перевірки й звіт.
