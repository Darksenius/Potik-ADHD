# Потік 1.7.5.r4

Окремий виправлений реліз із усіма змінами 1.7.5.r3. Усуває чорний екран при відкритті застосунку на Android, коли фонове сповіщення вже працює.

## Виправлення

- Усунуто помилку запуску нативного мосту: встановлений у APK Capacitor повертає обробник слухача подій синхронно, а код помилково викликав у нього `.catch()`. Через це React не доходив до відображення інтерфейсу.
- Підключення слухача підтримує синхронний результат і Promise; помилка підключення більше не перериває старт інтерфейсу.
- Формат збережених задач, нотаток, блокнота та прогресу не змінено.
- Додано два регресійні тести з фактичним `native-bridge.js`, який потрапляє в APK: чистий запуск і запуск зі збереженими даними та дією зі сповіщення.
- Назва APK при ручній збірці більше не залежить від назви гілки. Автоматично зібраний реліз спочатку створюється як чернетка для перевірки підписаного APK.

## Перевірка

- TypeScript, production-збірка Vite, вбудовування вихідного коду та Capacitor sync — успішно.
- Playwright: **24/24** сценарії пройшли.
- Android 9 / API 28, WebView **66.0.3359.158**, ізольований емулятор: відтворено збій r3; у r4 перевірено чистий запуск, сім вкладок, створення задачі, збережені задачу/нотатки/блокнот/досвід, виконання задачі кнопкою шторки, повернення з фону та перезапуск процесу.
- У перевірених запусках r4 немає `Uncaught TypeError` або `FATAL EXCEPTION`.

Ці перевірки не охоплюють усі моделі телефонів, налаштування економії батареї виробників і довготривалу доставку будильників. Фізичний телефон користувача не підключений до тестового середовища.

Версії: Android **1.7.5.r4**, versionCode **1070504**, npm **1.7.5-r4**. APK є повним застосунком, а не окремим патчем. Для збереження наявних даних не потрібно видаляти попередній застосунок або очищувати його сховище.
