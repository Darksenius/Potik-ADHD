# Потік 1.7.6.r9 · «Що нового» для власника

У налаштуваннях є окремий пункт «Що нового». Пояснення написані від першої особи для власника: зміни, дії для перевірки на його телефоні, очікуваний результат, уже перевірене й незавершене. Поточна версія відкрита першою; r8 можна розгорнути нижче. Текст входить до APK і доступний без інтернету.

Записи: `src/content/release-notes.json`. Кожен наступний реліз має додавати особистий запис першим; збірка відхиляє відсутній запис поточної версії. Новий JSON і перевірка збірки включені у вбудований вихідний код. Правило записане в `docs/WORKFLOW.md`.
