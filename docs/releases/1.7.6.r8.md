# Потік 1.7.6.r8

Виправлення менш очевидних переходів: повторне швидке збереження без дубля, конфлікти зон при імпорті, однаковий добір зон, перевірка часових проміжків, очищення старих сигналів, порядок дій зі шторки та повтори при закритому інтерфейсі.

Android перебудовує локальний розклад після зміни часу/часового поясу. Старі кнопки сповіщення не застосовуються до нового виконання. Збережені перенесення й snooze зберігають свої абсолютні моменти.

[Звіт і межі перевірки](../qa/edge-cases-r8-2026-10-14.md). Кандидат очікує фінальну перевірку Android та публікацію підписаного APK; r7 лишається незмінною.
