# Потік 1.7.5.r3

Цей реліз завершує основну міграцію вебзастосунку на React, TypeScript, Vite та Zustand і містить виправлення, перевірені під час аудиту.

## Що змінилося

- Додано надійніше автозбереження, відновлення з резервної копії, нагадування, повторювані задачі та внутрішній банер будильника.
- Виправлено відкриття редактора задач, вибір локальної дати планувальника, оновлення щоденника й календаря та обробку нативних подій Android.
- Додано редагування й вимкнення зон, кошик із відновленням задач і налаштування одиниць для регулярних дій.
- Виправлено переповнення нотаток на вузьких екранах і застарілий банер задач після видалення.
- Додано автоматичні браузерні перевірки для основних сценаріїв міграції.

## Перевірка

- Production-збірка Vite і вбудовування ліцензії та вихідного коду пройшли успішно.
- Playwright: 22 із 22 сценаріїв пройшли.
- Android debug APK зібрано успішно; підписаний release APK збирається GitHub Actions.

Android versionCode піднято з 10705 до 1070503, щоб оновлення встановлювалося поверх попереднього релізу.
