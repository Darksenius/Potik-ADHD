Станом на 21.10.2026. Перед змінами прочитайте `AGENT_INSTRUCTIONS.md`, `docs/WORKFLOW.md` і N1–N5 у `docs/roadmap/NATIVE-MIGRATION.md`.

## Продукт і правила

Потік — офлайн Android-органайзер для дорослих з РДУГ: повний список задач, часові зони, план дня/тижня, нотатки й швидке введення зі шторки. Стек — Kotlin/Compose та один транзакційний Repository для UI й сповіщень. [Карта застосунку та продуктового задуму](APP-MAP.md) описує кожен екран і стан сповіщення; [дослідження Maestro та альтернатив](roadmap/E2E-TOOLING.md) не означає їх встановлення чи впровадження.

Зони дня і є напрямками справ, окремий другий перемикач напрямків не додавати. Проста задача може не мати часу, дати чи зони; це звичайна задача, не «Вхідні».

- «Задачі» одразу показують усі справи, п’ять найближчих стоять першими. «Доречні зараз» не має ліміту п’яти; одна постійна панель сповіщення показує до п’яти доречних задач із гортанням. Закріплені пріоритети йдуть першими лише якщо підходять поточній зоні, даті й часу.
- Для запланованої справи «Не зараз» — година (інша тривалість доступна в застосунку). Для звичайної справи переносить у наступну іменовану зону сьогодні, пропускаючи проміжки. Якщо у цій зоні задачу не виконано й знову не відкладено, вона повертається до початкової зони й показується при наступному її входженні; до того доступна в Плані/усіх задачах.
- Після останньої зони сьогодні «Не зараз» виконує правило «Не сьогодні».
- «Не сьогодні»: прив’язана задача — завтра у власну зону; без прив’язки — рівно на 23 години. Постійна прив’язка й повторення не переписуються.
- Пресет на дві дати створює незалежні виконання; повторне застосування до тієї самої дати не створює дублів і не скидає галочки.
- Активні дні не скидаються через пропуск. Перша змістовна дія дня відкриває наступну із 100 локальних думок; саме відкриття застосунку досвіду не дає.
- Блокнот автозберігається без кнопки. Швидка задача й нотатка зі шторки мають зберігатися без Activity/JS; повторна доставка не дублює запис або досвід.

Не повертайте Pomodoro, дитячу звичку, окремий водний шар чи «Вхідні». Віджет і великий редизайн поза цим переходом.

## Чистий клон і APK без Node

Потрібні JDK 21 та Android SDK 36; для APK не потрібні Node/npm або секрети підпису. Збірки `debug` і `nativeDebug` не потребують емулятора; запуск instrumentation потребує окремого API28 емулятора.

```powershell
git clone --branch main https://github.com/Darksenius/Potik-ADHD.git Potik
cd Potik
git status --short
git log -3 --oneline
$env:JAVA_HOME = '<JDK 21 path>'
$env:ANDROID_HOME = '<Android SDK 36 path>'
cd android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
.\gradlew.bat :app:assembleNativeDebug
.\gradlew.bat -PflowTestBuildType=nativeDebug :app:connectedNativeDebugAndroidTest
```

Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Окремий `nativeDebug` APK: `android/app/build/outputs/apk/nativeDebug/app-nativeDebug.apk`; він має application ID із суфіксом `.native` та окремі дані. Самої компіляції instrumentation недостатньо — потрібен запуск на API28.

## Уточнення поведінки r29 (21.10.2026)

Зворотний зв’язок власника замінює попереднє обмеження п’яти задач на екрані: вкладка «Задачі» одразу містить усі нетрашовані записи. На початку — п’ять найближчих; TaskOrder ранжує доступні пріоритети, належні за часом, поточну зону, найближчий час/наступну зону й загальні справи. Фільтр «Доречні зараз» теж не обмежений п’ятьма.

Сповіщення 42 — єдина постійна панель: до п’яти доречних справ, стрілки, виконання, перенесення, ± лічильника, окремі RemoteInput для задачі/нотатки. Після дії не створювати картки 1000..1100. Вибір сторінки — лише UI preferences, не другий writer задач. Зберігати generation-захист дій і Undo.

///12:40/// у назві перетворюється на заплановану задачу; без обраної дати — сьогодні, якщо час попереду, інакше завтра. Явна дата з редактора/Плану зберігається. Маркер прибирається з назви, нотатки не парсяться. Спільний TaskTitleSchedule використовується всіма входами.

Для sched «Не зараз» — година, у застосунку також 15/30/60 хв і своя тривалість. Нове значення існуючого questDeferral.kind = time з startAt — одноразове перенесення, яке після дедлайну не блокується старою зоною/датою. Первісний розклад не переписується. Контракт оновлено одночасно в Kotlin, Java й валідаторі; схема Room не змінена. Звичайні задачі й «Не сьогодні» зберігають попередні правила. Слово «квест» у новому UI не використовувати; persisted/internal назви не перейменовувати.
