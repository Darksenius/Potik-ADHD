# Потік: початок роботи для ШІ

Міркування, робота й відповіді — українською або англійською.

Перед змінами прочитай:

1. [AGENT_INSTRUCTIONS.md](AGENT_INSTRUCTIONS.md) — обов’язкові межі, дані, перевірки та реліз.
2. [docs/CONTINUING-WORK.md](docs/CONTINUING-WORK.md) — передача роботи іншому розробнику/ШІ: зроблене, неперевірене, наступні кроки та паралельна робота.
3. [docs/WORKFLOW.md](docs/WORKFLOW.md) — короткий цикл розробки й умови публікації.

Звір поточні `git status`, гілку й `git log`; стан checkout має перевагу над застарілим описом етапу. Не скидай незакомічені зміни. Активний застосунок — Kotlin/Compose у `android/`; `archive/web-reference/` — історична вебреалізація, її не потрібно повертати в APK.

Працюй над одним завершеним сценарієм. Дані фізичного телефона не очищати; для перевірок — окрема `.native` збірка на тестовому Android 9. Реліз публікувати лише після готовності й перевірки підписаного APK.
