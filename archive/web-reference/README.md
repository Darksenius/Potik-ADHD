# Historical web implementation

The React/TypeScript application, browser tests and web build tools are preserved here as migration reference. The moved files were verified byte-for-byte with SHA-256. Original package metadata is included; this directory is not an active build target and is not packaged into the Android APK.

The complete former layout is available at Git commit `ec0a2120a369bfd5c4ea7bb0c54c5ef3ed6e3888`. Native JVM tests retain the captured comparison fixtures under `android/app/src/test/resources/`. Authored content remains in the active `src/content/` catalog and is packaged directly by Gradle.

Use the root README for the current native application and release process.
