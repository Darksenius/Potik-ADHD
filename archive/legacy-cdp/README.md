# Історичні CDP-експерименти

Ці два скрипти належать до монолітної HTML-версії. Вони використовують CommonJS, глобальний стан `S`, `mergeState` і `render*`, яких немає в поточному React-застосунку. Формат `.js.txt` зберігає матеріал для порівняння без враження, що це робочі команди.

Не використовувати їх для імпорту даних або перевірки сучасного застосунку. Актуальні сценарії — `tests/` (Playwright), `android/app/src/test/` (JVM) і `android/app/src/androidTest/` (Android). Команди — у [README](../../README.md) та [інструкціях для роботи](../../AGENT_INSTRUCTIONS.md).
